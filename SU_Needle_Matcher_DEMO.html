About this Demo

This is a marketing preview of SU Needle Matcher. It uses a small fixed set of sample needles so you can explore the look, workflow and graphs.

The full application contains the complete official tables, full matching engine, variable-length handling, author tools and password protection.

Demo password: demo

How the real app works

1. Select the correct jet / spring-or-fixed table
2. Load a known needle or enter measured station diameters
3. Click Find Matches to see closest shape match plus richer / leaner alternatives
4. Use the graphs and Direct Compare for visual confirmation
